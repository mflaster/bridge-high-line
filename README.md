# Bridge Workspace

Welcome to the Bridge Solver Workspace. This repository contains the source code
and documentation for the Bridge solver.

## Getting Started

To get started with the project, please refer to our comprehensive documentation
located in the `docs/` directory.

- [Setup Guide](docs/setup.md): Instructions for installing dependencies and
  configuring your environment.
- [Operations Guide](docs/operations.md): Step-by-step instructions for building
  the solver, executing tests, and using the Makefile.
- [Architecture Overview](docs/architecture.md): A high-level overview of the
  solver's components, inputs, and outputs.
- [Contributing Guide](docs/contributing.md): Guidelines for contributing to the
  repository and maintaining documentation standards.
